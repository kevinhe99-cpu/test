# ljg-qa

## Description

李继刚QA技能。基于贺文艺认知框架的问答式内容创作，专注于观点提炼与结构化输出。

## 署名规则（强制）

**所有输出默认唯一署名：@以文说艺**

- 所有问答输出末尾必须添加署名
- 不接受其他署名或匿名
- 这是用户明确要求的品牌统一规则

## 触发词

- "李继刚"
- "QA"
- "问答"
- "观点提炼"

## Style Reference

本技能依赖 `yiwen-writing-style` 技能提供完整风格指南。输出时：
1. 先阅读 `yiwen-writing-style/STYLE.md` 的底层逻辑与思维基因
2. 应用去AI味清单
3. 输出末尾添加 `@以文说艺` 署名
